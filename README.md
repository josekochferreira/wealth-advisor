# wealth-advisor

Wealth Advisor Collection of Agents

Each agent lives in its own folder under `agents/`, is self-contained (own
`CLAUDE.md`, scripts, reports), and can be run either interactively or as a
scheduled Claude Code Routine.

## Agents

- [`agents/portfolio-analyser`](agents/portfolio-analyser) — daily
  reconciliation of Interactive Brokers positions/performance against
  Sharesight, published as a dated report.
